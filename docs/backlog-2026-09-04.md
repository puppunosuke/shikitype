## A. 入力・編集の基礎

- [x] **A1 Undo/Redo（Ctrl+Z / Ctrl+Shift+Z、Mac は Cmd+Z / Cmd+Shift+Z）の実装**
  対象は式の編集、行の作成・削除など**行モードとキャンバスモードで共通の動作のみ**。
  キャンバスモードの位置変更（ブロックのdrag移動）は対象外。
- [x] **A2 変換入力モードで従来キー／記号キーが生きている状態を排除**
  Ctrl+Zを押したつもりで `≧` が出るのが強い不満。変換入力モード中は旧キー割当を無効化する。
- [x] **A3 Shift+Enter で1ブロック内改行**
- [x] **A4 「ぶんしょう」「てきすと」で文キーを変換できるようにする**
- [x] **A5 構造キーを一項として扱う**
  ∫・分数・括弧など式を内包するキーは、中身の有無にかかわらず一つの項として扱い、
  **式の中にカーソルがある場合を除き、Backspace一回で全体が消える**。
  中身が無い／消えた括弧・∫・分数が消えなくなる事象が頻発している。
  ※ `fd10421` の「空構造の共通削除契約」と重なる領域。既存実装との整合を先に確認する。
- [x] **A6 式を選択可能にする＋コピー&ペーストの実装**
